# CE-POLY-06 — Polyphony Complexity Metadata

Adds deterministic benchmark metadata for segmentation by:

- voice count
- staff count
- simultaneous-note density
- overlap density
- cross-staff presence
- tuplet presence
- tie density
- grace presence
- bounded rhythmic-complexity index

The index is descriptive benchmark metadata, not musical authority and not a correction signal by itself. No solver score or production threshold is changed by this stage.
