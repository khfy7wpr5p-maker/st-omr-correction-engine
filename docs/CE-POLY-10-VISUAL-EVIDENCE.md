# CE-POLY-10 — Visual / Image-Localized Evidence Contract

This stage does not add image recognition. It allows trusted upstream localization to bind a semantic score event to an explainable source region using:

- page
- system ID
- measure ID
- staff ID
- bounding box
- image crop reference
- localization confidence
- separate source-quality metadata

Source quality remains evidence metadata and cannot independently create a semantic correction. Production correction policy is unchanged.
