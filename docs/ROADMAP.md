# Roadmap

| Stage | Scope | Production mutation |
|---|---|---|
| E0 | Safe repo, CI, contracts, architecture/safety policy | None |
| E1 | Canonical correction data model | None |
| E2 | Candidate graph + bounded search | None |
| E3 | Meter/rhythm/onset constraints | None |
| E4 | Candidate resolver | Shadow only |
| E5 | Polyphonic voice solver | Shadow only |
| E6 | Classical guitar profile | Shadow only |
| E7 | Piano profile | Shadow only |
| E8 | Patch/revert model | Controlled, not auto-applied |
| E9 | SesliTab adapter | Shadow only |
| E10 | Teacher evidence + benchmark | Shadow only |
| E11 | Controlled automatic correction | Safety gate; explicit approval required |
| E12 | Optional visual second-opinion AI | Evidence only |

E0-E10 must preserve source immutability and may be developed without production auto-correction. E11 is a separate authorization boundary.
